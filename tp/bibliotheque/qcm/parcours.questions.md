## Lequel affiche le tableau `t` de la fin vers le début ? {#q .single}

- [ ] `for (int i = t.length; i > 0; i--) { System.out.print(t[i]); }`
- [x] `for (int i = t.length - 1; i >= 0; i--) { System.out.print(t[i]); }`
- [ ] `for (int i = 0; i < t.length; i++) { System.out.print(t[i]); }`
